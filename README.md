# sjonni/tap

Homebrew tap for **pingari**, a terminal tool that scans the network you're
plugged into, watches every device, and alerts you (terminal, notification,
phone) the moment one stops responding — with the switch port it was on.

```sh
brew install sjonni/tap/pingari
pingari
```

Update with `brew upgrade pingari`. The macOS program is signed and notarized
by Apple. Release files are published here by pingari's release script.
